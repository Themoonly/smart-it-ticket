## แนวคิดของ Domain

ในองค์กรทั่วไป พนักงานแจ้งปัญหา IT ด้วยข้อความภาษาพูด เช่น "เน็ตหลุด", "ปริ้นไม่ออก", "ลืมพาส"
เจ้าหน้าที่ด่านหน้าต้องอ่านทีละข้อความแล้วส่งต่อให้ช่างที่ถูกต้องเอง ทำให้ช้าและส่งผิดทีมได้ง่าย

ระบบนี้รับข้อความแจ้งปัญหา แล้วใช้เทคนิค NLP เพื่อ

1. ลบข้อมูลส่วนตัว (URL, อีเมล, เบอร์โทร) ออกจากข้อความ
2. จัดหมวดหมู่ปัญหาและหมวดย่อย แล้วส่งตั๋วไปยังทีมที่ดูแล
3. สกัดข้อมูลสำคัญ (อุปกรณ์, สถานที่, เวลา) ให้ช่างเห็นทันทีโดยไม่ต้องอ่านซ้ำ
4. ประเมินความเร่งด่วน (High / Medium / Low)
5. ส่งตั๋วที่ระบบไม่มั่นใจเข้าคิว Human Review แทนการเดา

| หมวดหมู่ | หมวดย่อย | ทีมที่รับผิดชอบ |
|---|---|---|
| Network | Wi-Fi หลุด / สัญญาณอ่อน, LAN สาย/พอร์ตเสีย, VPN, อินเทอร์เน็ตช้า/เข้าเว็บไม่ได้ | Network Engineer Team |
| Hardware | เครื่องเปิดไม่ติด/ไฟไม่เข้า, ปริ้นเตอร์, อุปกรณ์ต่อพ่วง | Hardware Technician Team |
| Software | บัญชี/รหัสผ่าน, โปรแกรม/แอป, อีเมล | Software Support Team |
| General Support | ข้อความที่จัดหมวดไม่ได้ | Frontline Helpdesk (Human Review) |

## เทคนิค NLP ที่ใช้

| เทคนิค | ใช้ทำอะไร | โค้ด (`nlp_utils.py`) |
|---|---|---|
| **Regex & Cleansing** | ลบ URL, อีเมล, เบอร์โทร (รองรับ `081-234-5678`, `+66`) และคำว่า "โทร" ที่ค้างอยู่ ลบสัญลักษณ์ | `remove_pii()`, `clean_text()` |
| **Normalization** | แปลงตัวพิมพ์เล็ก, ตัดคำลากเสียง (`มากกกก` → `มาก`), ตัดไม้ยมก, แปลงคำสะกดหลายแบบเป็นคำมาตรฐาน (`ไวไฟ` → `wifi`, `พาสเวิร์ด` → `รหัสผ่าน`) | `normalize_text()`, `SYNONYMS` |
| **Tokenization & Stopwords** | ตัดคำด้วย PyThaiNLP `newmm` + custom dictionary คำศัพท์ IT และปรับ stopword list ให้เหมาะกับงาน | `process_tokens()` |
| **Topic Identification** | ให้คะแนนแต่ละหมวดจากคำเดี่ยว (1 คะแนน) และวลี regex (2 คะแนน) คำนวณ Confidence = คะแนนหมวดที่ชนะ / คะแนนรวม | `classify_topic()` |
| **NER (rule-based)** | สกัด DEVICE (พจนานุกรม), LOCATION (regex เช่น `ห้อง B4-01A`, `ชั้น 3`, `แผนกบัญชี`), TIME (`เมื่อเช้า`, `14:30`) | `extract_entities()` |
| **POS Tagging** | ใช้ `pos_tag` ของ PyThaiNLP (corpus `orchid_ud`) เลือกคำนามและคำกริยาเป็นคำสำคัญ | `extract_keywords_pos()` |

### การปรับ Tokenization

ถ้าใช้ `thai_stopwords()` ของ PyThaiNLP ตรง ๆ จะมีปัญหา 2 อย่าง

1. `newmm` ตัด "ครับผม" และ "สัญญาณไฟ" เป็นคำเดียว ทำให้ลบ stopword ไม่ออก และจับคีย์เวิร์ด "ไฟ" ไม่ได้
   แก้โดยเอาคำเหล่านี้ออกจากพจนานุกรม (`SPLIT_WORDS`) เพื่อบังคับให้แยก
2. stopword list มาตรฐานมีคำที่สำคัญกับงานนี้ เช่น "รับ", "เข้า", "เปิด", "ช้า"
   แก้โดยเอาคำเหล่านี้ออก (`KEEP_WORDS`) และเพิ่มคำฟุ่มเฟือยภาษาพูด (`EXTRA_STOPWORDS`)

ผลลัพธ์: `คือว่ากล่องรับสัญญาณไฟไม่เข้าเลยครับผม` → `['กล่อง', 'รับ', 'สัญญาณ', 'ไฟ', 'เข้า']`

การจับวลี เช่น "เข้าเว็บไม่ได้" หรือ "ไฟไม่เข้า" ทำบนข้อความก่อนลบ stopword
เพื่อไม่ให้คำปฏิเสธ "ไม่" หายไปก่อนจัดหมวด

## ข้อจำกัด

- ตัวจำแนกเป็นแบบ rule-based (คีย์เวิร์ด + regex) ข้อความที่ใช้คำนอกพจนานุกรมจะตกเป็น General Support
  และถูกส่งเข้าคิว Human Review
- `test_tickets.csv` ใช้ประกอบการออกแบบกฎด้วย Accuracy ที่ได้จึงสูงกว่าข้อความใหม่ที่ระบบไม่เคยเห็น
- ฐานข้อมูล SQLite บน Streamlit Community Cloud จะถูกล้างเมื่อแอป restart หรือ redeploy
  กด "โหลดตั๋วตัวอย่าง" เพื่อเติมข้อมูลเดโมใหม่ ถ้าใช้งานจริงควรเปลี่ยนเป็นฐานข้อมูลภายนอก

## แนวทางพัฒนาต่อ

- เปลี่ยนตัวจำแนกเป็น TF-IDF + Logistic Regression / XGBoost และใช้ `predict_proba()` เป็น Confidence Score
- นำตั๋วที่ช่างกด "ส่งผิดทีม" มาเป็นข้อมูลเทรนเพิ่ม
- ทดลอง WangchanBERTa เปรียบเทียบความแม่นยำกับทรัพยากรที่ใช้

## ตัวอย่าง Prompt ที่ใช้สั่ง AI

ใช้ Claude (Anthropic) เป็นผู้ช่วยวิเคราะห์งานและเขียนโค้ด

1. **วิเคราะห์โจทย์และงานเดิม**
   > วิเคราะห์ไฟล์งานใน context แล้วอธิบายงานให้หน่อย โดย 1. วิเคราะห์ภาพรวมของงานทั้งหมด
   > 2. วิเคราะห์ว่างานต้องการอะไร 3. วิเคราะห์ว่างานนี้ต้องเพิ่มเติมอะไร และแนะนำแนวทางในการปฏิบัติให้หน่อย

2. **ออกแบบระบบติดตามตั๋ว**
   > ระบบนี้ควรมีหน้าต่างแยกสำหรับดูว่า คำขอถูกส่งไปที่ทีมดูแลจริงไหม

3. **เขียนโค้ดทั้งระบบ**
   > เขียนโค้ดครบทั้งชุดนี้ให้ได้เลย รวมการแก้ tokenization จากรอบก่อนด้วยเลย

4. **โค้ดเวอร์ชันแรก (ใน Google Colab)** — _แก้เป็น prompt ที่ใช้จริงตอนทำเวอร์ชันแรก_
   > สร้าง Streamlit app จัดหมวดหมู่คำร้อง IT Support ภาษาไทยเป็น Network, Hardware, Software
   > ใช้ regex ลบลิงก์ เบอร์โทร อีเมล ตัดคำด้วย pythainlp และลบ stopwords
